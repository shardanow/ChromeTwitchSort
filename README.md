# Twitch New First

Chrome-расширение для страницы категорий Twitch (`twitch.tv/directory`).

## Возможности

- Блок «НОВОЕ» сверху с заголовками-разделителями («НОВОЕ» / «Все категории»)
- Кнопка «Загрузить все»: прокрутка списка до заданного порога зрителей (0 — до конца)
- Открытие карточек категорий в новой вкладке
- Кнопка «наверх» в правом нижнем углу
- Пересортировка при подгрузке карточек (ручной и автоматической)
- Иконка расширения серая на других сайтах, цветная — только на `twitch.tv/directory`

## Установка

1. Склонируйте или скачайте репозиторий
2. Откройте `chrome://extensions`
3. Включите «Режим разработчика»
4. Нажмите «Загрузить распакованное расширение» и выберите папку проекта

## Настройки

Клик по иконке расширения открывает попап:

- Поднимать «НОВОЕ» наверх
- Заголовки-разделители блока «НОВОЕ»
- Порог зрителей для остановки загрузки
- Кнопка «Загрузить все»
- Открывать карточки в новой вкладке
- Кнопка «наверх»

Настройки применяются сразу на открытых вкладках.

## Примечания

- Работает на `twitch.tv/directory` и `twitch.tv/directory/all`
- Сортировка и порог зрителей зависят от разметки Twitch; при её изменении могут потребоваться правки селекторов в `content.js`
